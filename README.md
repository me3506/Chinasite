# SunGrid Hybrid Solar Inverter Landing Page

**EEEMART** — Reliable Power for a Brighter Tomorrow

Modern, SEO-friendly landing page for SunGrid Hybrid Solar Inverters in Bangladesh.

## Features

- Clean & responsive UI
- WhatsApp order integration (pre-filled messages)
- Full product price list (Retail + Wholesale)
- Order form → WhatsApp
- Floating WhatsApp button
- SEO optimized (meta tags, Open Graph, Schema.org)

## Local Run

```bash
npm install
npm start
```

Open: http://localhost:3000

## Deploy to Railway (via GitHub)

1. Create a new repository on GitHub
2. Upload all files from this folder
3. Go to [Railway.app](https://railway.app) → New Project → Deploy from GitHub repo
4. Select this repository
5. Railway will auto-detect Node.js and run `npm start`
6. Generate a domain from Railway dashboard

### Environment

No environment variables needed. Static site.
